## 一、这一版解决的两个「玩不下去」

### 1. 复盘页点不动

**现象**：打完一场，复盘页只看到雷达图和半截技术统计，右下角没有任何按钮。玩家以为卡死，只能刷新页面——进度全丢。

**原因**：复盘页整页是一个 `VBox`，`head + 三栏内容 + vfill + foot`。竖屏下三栏变单列后内容高度轻松超过 852，`foot`（含「下一轮」「返回」）被推到屏幕之外。`vfill` 反而把按钮顶得更远。

**修法**：竖屏把正文包进 `SmoothScroll`，`foot` 留在滚动区之外固定在底部。

```
VBox
├─ SmoothScroll (EXPAND_FILL)
│   └─ VBox: head / 雷达 / 统计 / 叙事
└─ foot  ← 固定，永远可点
```

外边距同时从 46/28 收到 16/14。

### 2. 更新了却看不到

**现象**：每次改完都说「已部署」，玩家打开还是昨天的界面。

**原因**：Godot 导出的 `index.service.worker.js` 把 `index.html` 也写进了预缓存列表。Service Worker 是 cache-first，所以壳子永远是第一次那个，里面的构建号、脚本全都不会更新。

**修法**（`tools/patch_web.py`）：

1. 从 SW 的 `CACHED_FILES` 里摘掉 `index.html`，让壳子走网络
2. 在 `<head>` 注入构建号自愈脚本：

```js
if (seen && seen !== BUILD) {
    注销所有 SW → 清空 CacheStorage → location.reload();
}
```

首次访问只记录构建号不清除，避免平白多下一次 10MB wasm。

## 二、v0.81 核心：时间流

### 设计取舍

原设计是「点下一周」的回合制，中后期长草期极度消耗耐心。v0.81 改为开罗式时间流：**时间自己走，玩家只在关键节点介入**。

但完整照搬文档（7 天排程表编辑、连锁事件、赛事备战模式）工期不可控，所以这一版先落地**主干**，把「能自动玩下去」跑通：

| 文档要求 | 本版状态 |
|---|---|
| 现实 1 秒 = 游戏 1 天 | ✅ 已实现 |
| 暂停 / 1× / 2× / 4× | ✅ 已实现 |
| 事件、体力、赛事自动暂停 | ✅ 事件 + 体力；赛事待接 |
| 训练改排程 | ⚠️ 有默认 7 天排程，但还没有编辑 UI |
| 事件降频到每月 1–2 次 | ✅ 每周必抽 → 每天 4.5% |
| 连锁事件 | ❌ 未做 |
| 后台暂停 | ✅ 靠 `_can_flow()` 的门控实现 |

### 架构

```
TimeManager (autoload)
  time_scale: 0 / 1 / 2 / 4
  SECONDS_PER_DAY = 1.0
  _process: 累加 delta × scale，满 1 秒调一次 GameManager.advance_day()
  _can_flow(): 不在生涯页 / 有弹窗 / 有比赛 → 不流动
```

```gdscript
GameManager.advance_day():
  1. 按 schedule[day] 执行当天安排（训练 / 休息 / 文化课）
  2. 伤病按天倒计时（7 天折 1 周）
  3. day += 1，越过 7 就调 advance_week() 做周结算
  4. 每天 4.5% 概率抽事件，抽中就 should_pause
  5. 体力 < 20 → should_pause
  返回 {should_pause, pause_reason}，由 TimeManager 决定归零
```

`advance_week()` 保留，降级为「周结算」：week+1、跨年、年龄、积分衰减、AP 重置、排名更新。原来它自己抽事件那行删掉了，否则一周一次太密。

### 体力曲线（这版调了三轮）

第一版直接沿用「一周一次训练」的消耗（tech −11 体力），时间流下一天一次，两天就趴下，时间流永远卡在「体力见底」的暂停点。

调整：

```
每天训练后补回 +7.5 体力   （单日训练量远小于原来攒一周）
休息日恢复 +9.0（原 +4.5）
体力 < 28 自动改休息        （不是硬撑，也不是报警）
体力 < 20 才触发自动暂停
```

调整后 4× 档跑 3.5 秒推进 14 天，体力稳定在 100。

### UI 变更

底部导航的「下一周 →」按钮换成时间控制：

- **竖屏**：`跑/停` + 倍速循环（1× → 2× → 4× → 1×），两个键 82px，给四个 tab 留出空间
- **横屏**：四档平铺，一眼看到当前档位

顶栏和正文标题都跟随日期刷新（`第 N 周 · 周X`）。这里踩了个坑：只刷新顶栏，正文标题还写着「第 1 周」，玩家会以为时间没走。现在 `_on_day_changed` 两处都更新。

| 成就第一周全解锁 | 名次类指标被当成累计量（999 ≥ 1 恒真）。加 `LOWER_IS_BETTER` + `UNRANKED`，改 `<=` 判定 |

## 五、已知问题 / 下一步

1. **排程没有编辑 UI**。现在用默认的「练练练练练休文」，玩家改不了。需要一张 7 天格子的表。
2. **赛事没有接进时间流**。文档要求「比赛周周一自动暂停弹赛程表」，目前仍要手动去赛事页报名。
3. **连锁事件未做**。`脚踝扭伤 → 继续高强度 → 跟腱撕裂` 这条链需要事件系统支持「延迟触发」。
4. **教练谈话 / 升学审批**没接自动暂停。
5. 器材页 6px 溢出：`ScrollContainer` 把滚动条宽度算进最小宽度，需要改最小尺寸计算或换自定义滚动容器。

## 六、一句话

这一版把「一局一局点」变成了「看着人生自己走、关键时刻按暂停」。真正让它可玩的不是时间流本身，而是那几个刹车点——体力见底、有事发生、比赛周，时间会自己停下来等你。
