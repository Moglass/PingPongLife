## 一、执行摘要

这是一个**核心循环完整、可从头玩到退役的垂直切片**，技术上达到了「可以发出去让人玩」的标准，内容上还差一次体量扩张和一轮平衡调优。

三句话概括：

1. **能玩完**——从 8 岁市体校到退役，训练、比赛、排名、论坛、成就、团体赛全链路闭合，没有死路。
2. **能跨端**——同一份 GDScript 出 Windows exe 和 Web/WASM，iPhone Safari 打开即玩，桌面/竖屏两套布局。
3. **不能叫成品**——内容量偏低（35 张事件卡、37 站赛事）、难度曲线只做过一轮校准、没有新手引导和存档云同步。

如果要给它一个准确的位置：**Early Access 首发版本，或发行商 pitch 用的可玩 Demo**。距离商业正式版还差内容与打磨，不差技术底座。

## 五、架构评价

### 做得好的

**1. 规则与表现彻底分离**

`MatchEngine` 是纯逻辑，`MatchView` 消费事件。四档速度（沉浸/战术/快进/跳过）共用同一条 RNG 序列，跳过不会少赢一场、也不会多拿经验。这是很多体育游戏做不到的。

**2. 数据驱动**

37 站赛事、143 个成就、28 件器材全在 `StaticDB.gd` 里，策划改表不用动代码。

**3. 平台适配层**

`scripts/platform/` 六个适配器把 `OS.has_feature()` 之类的判断收口，页面代码里不出现平台分支。Web 端踩的坑（无系统字体、触摸事件、SW 缓存）全部集中在这里和 `patch_web.py`。

**4. 可测试性**

11 个 headless 测试场景，加上 `AuditRunner`（控件越界扫描）和 `test_fuzz`（逻辑压测）。改动 UI 或数值后能在 3 分钟内跑完全套。

### 欠得多的

**1. UI 层是全项目最脆的部分**

`MainUI.gd` 单文件 900+ 行，页面路由、顶栏、导航、弹窗、toast、存档迁移全在里面。`CareerView` 和 `ProfileView` 也各自 400+ 行，且都靠 `UIKit.is_portrait()` 分叉出两套布局——横屏和竖屏是两份代码，改一处要记得改另一处。

> 建议：把 `_build_portrait` 系列抽成独立的 `*PortraitView`，让布局分叉变成策略选择，而不是 if-else 复制。

**2. 缺乏统一的状态机**

`GameManager.phase`（TITLE/CAREER/MATCH/TEAM/RETIRED）+ `pending_event` + `active_run` + `team_run` + `PauseManager._reasons`，五个状态变量之间没有互斥约束。现在靠人工保证「比赛时不会有事件弹窗」，但没有任何断言拦着。

> 建议：引入一个显式的 `GameState` 枚举 + 合法性校验，非法转换直接报错。

**3. 没有资源/内存管理**

Web 端 37.7 MB wasm 是固定的（Godot 单线程导出），无法按需加载。纹理几乎没有（全程序化绘制）所以内存压力不大，但没有做过长时间运行的泄漏测试。

## 八、距离「商业可交付」的差距

按独立游戏 EA 上线的常见标准逐项对照：

| 维度 | 现状 | 达标 | 差距 |
|---|---|---|---|
| 核心循环闭合 | ✅ | 必须 | — |
| 无阻断性 bug | ✅ 0 问题 | 必须 | — |
| 跨平台可运行 | ✅ Web/Windows | 必须 | iOS 缺真机 |
| 内容时长 | ~3–5 小时到退役 | 8+ 小时 | **需扩内容** |
| 新手引导 | ❌ | 建议有 | 缺 |
| 音效音乐 | 程序化合成 | 建议有 | 可接受 |
| 存档可靠性 | 本地 + 存档码 | 必须 | 基本达标 |
| 平衡性 | 一轮校准 | 需要 | 缺分布测试 |
| 本地化 | 仅中文 | 视市场 | — |
| 商店素材 | ❌ | 必须（若上架） | 缺 |

**结论**：技术上已过线，内容与包装未过线。

## 九、建议的下一步（按投入产出排序）

1. **扩事件池到 100+ 张**（最高优先）。这是玩家中期体验的唯一变量来源，35 张周转太快。
2. **加 3 步新手引导**。第一次进游戏时解释「时间流怎么跑」「排程怎么改」「比赛在哪报名」。
3. **数值分布测试**。跑 50 组不同种子，看 26 岁 Ovr 的分布区间，现在只验证了单条曲线。
4. **UI 层重构**（技术债）。把 `_build_portrait` 拆成独立类。
5. **连锁事件**。v0.82 文档给了方案（EventBus 延迟投递 + 可取消 timer），未实现。
6. **iOS 真机验收**。需要一台 Mac。
